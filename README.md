# ストーリーEnglish 聞く力編（リスニング特化アプリ）

「ストーリーEnglish」と同じ全52話の教材（書き下ろしオリジナル13話＋パブリックドメイン名作の書き直し39話、総25,890語・2,014文・フレーズ120）を使い、**リスニング力**を鍛えるための姉妹アプリです。単体HTMLファイルのみで動作します。

## 使い方（GitHub Pages公開手順）

1. このZIPを解凍する
2. GitHubで新規リポジトリを作成（例：`story-english-listening`、Public）
3. `index.html` と `README.md` をアップロード（Add file → Upload files）
4. Settings → Pages → Branch を `main` / `(root)` にして Save
5. 数分後に `https://（ユーザー名）.github.io/story-english-listening/` で公開

スマホのブラウザで開いてホーム画面に追加すれば、アプリのように使えます。

## 5つのトレーニング

- **3ステップ聞き取り**：音だけ → クイズで初聞き理解度を測定 → テキストを見ながら → もう一度音だけ＋クイズで伸びを確認。「英語の順序のまま、頭から理解する」ための基本コース。ステップ2では「🇯🇵 対訳」ボタンで段落ごとの日本語訳も表示でき、聞き取れなかった理由（音か意味か）を切り分けられます。対訳は全40話分を収録。
- **意味取りトレーニング**：フレーズを聞いて日本語の意味を素早く選ぶ（回答時間も表示）。
- **ディクテーション**：1文ずつ聞いて、単語チップを並べる／キーボード入力で書き取り。単語ごとに正誤を表示。
- **チャンク聞き**：文を意味のまとまり（チャンク）に区切って再生。ポーズで復唱。英文を隠す・自分の声を録音する機能付き。
- **まるごと暗唱チャレンジ**：テキストを「全文→キーワードのみ→頭文字のみ→非表示」と隠しながら暗唱。全ての文を頭文字以上で言えたら認定。音声認識チェック対応端末では自動判定も可能。

## 聞き流しプレイリスト

話を選んで連続再生。再生速度（0.9/1.0/1.15倍）、おやすみタイマー（15/30/60分）、話の合間に意味取りクイズを1問挟む設定が使えます。

## 記録されるもの

初聞き理解度・再聞き理解度、意味取りベスト、ディクテーションベスト、暗唱の進捗、総リスニング時間。ブラウザの localStorage に保存されます（端末ごと）。

## 注意

- 読み上げ・音声認識は端末のブラウザ機能を使います（iPhoneはSafari、AndroidはChrome推奨）。
- 録音は、自分の声を端末内その場で聞き返すためだけのもので、外部に送信されません（音声認識を使う場合は端末の仕様に従います）。
- 教材の名作部分は、没後70年以上経過した作家のパブリックドメイン原典を独自に書き直したものです。
